# GoVizen — Technology Studio

> **WE BUILD • WE DESIGN • WE GROW**

GoVizen is a digital technology studio building modern web applications, AI systems, automation workflows, and custom enterprise software for forward-thinking businesses and startups.

---

## 🚀 Features

- **Interactive Project Cost & Timeline Estimator**: Real-time multi-step estimator with custom feature toggles, tech stack selector, and instant PDF/summary proposal generation.
- **AI Solutions & Automation Playground**: Interactive visual workflow pipeline builder demonstrating AI agent chains, webhook integrations, and automated operational triggers.
- **Client Project Inquiries & Booking Modal**: Direct strategy consultation scheduler with instant confirmation and quote summary.
- **Studio Portfolio & Case Studies**: Categorized showcase of client projects across Web Engineering, AI & Automation, SaaS Platforms, and Mobile Applications.
- **Dynamic Interactive Terminal**: Live developer playground console with studio diagnostics, command execution, and easter eggs.
- **Client Testimonials & Trust Indicators**: High-impact metrics, client success reviews, and verified delivery statistics.
- **Dark Luxury Aesthetic**: Modern UI with Tailwind CSS, Lucide icons, responsive mobile design, and subtle gold accents.

---

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: CSS transitions & Motion layout

## 📦 Getting Started

### Prerequisites

- Node.js 18+ and npm installed

### Installation

```bash
# Clone the repository
git clone https://github.com/<your-username>/govizen.git

# Navigate into the project directory
cd govizen

# Install dependencies
npm install

# Start the local development server
npm run dev
```

The application will be available at `http://localhost:3000`.

### Building for Production

```bash
# Compile and build production assets
npm run build

# Preview the production build locally
npm run preview
```
